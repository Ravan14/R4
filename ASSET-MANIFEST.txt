========================================================================
logo.webp    <- LOGO.png @128px   (header/footer mark and favicon)

WARNING when regenerating these: the checkout lives on a case-insensitive
volume, so a derived file named logo.png is the SAME FILE as LOGO.png and will
silently overwrite the 1024px source. Derived names below deliberately avoid
every case-variant of an existing filename.

BG.jpg is kept at 1200x630 and remains the og:image on every page; social
scrapers handle WebP unreliably, so it must not be replaced by BG.webp.

Do not place these files inside an assets, images, media, or videos subdirectory unless every website reference is deliberately revised.
